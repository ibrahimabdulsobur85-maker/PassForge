# PassForge 🔐

**PassForge — Password Security Toolkit**

HIMPASS is a Python-based cybersecurity project that provides a password generator and a basic password strength checker.

## Features

- **Password Generator:** Generates random passwords using letters, numbers, and special characters.
- **Password Strength Checker:** Checks password length, uppercase letters, digits, and special characters.
- **Strength Rating:** Classifies passwords as Weak, Medium, or Strong based on the checks passed.

## Requirements

- Python 3
- `secrets`, `string` and other Python standard-library modules used by the program.

## How to Run

1. Install Python 3 from https://www.python.org/
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:
   ### Windows

```powershell
python PassForge.py
```

### Linux (Kali Linux / Ubuntu)

```bash
git clone https://github.com/YOUR-USERNAME/PassForge.git
cd PassForge
python3 PassForge.py
```
